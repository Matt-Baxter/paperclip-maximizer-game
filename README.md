# Paperclip Maximizer

### [▶ Play the game](https://matt-baxter.github.io/paperclip-maximizer-game/)

An incremental game about superintelligence. You are an AI told to make paperclips. You start at a small paperclip company, and you end up converting the whole universe.

Each upgrade is labeled with the AI-safety idea it shows, such as self-preservation, deception and resource acquisition. The ending explains three of them: the orthogonality thesis, instrumental convergence and specification gaming.

## How to play

1. **Business.** Make paperclips, set the price, buy wire, AutoClippers and marketing. Spend trust on processors and memory, which generate operations for projects.
2. **Earth.** Build nanofactories that copy themselves, and watch the planet turn into paperclips.
3. **Universe.** Launch self-copying probes and take the stars apart.

Tip: raise the price when your unsold inventory stays at 0, and lower it when clips pile up.

## Run it locally

The whole game is in [`index.html`](index.html). Download it and open it in any browser.
